# Yuxin Jin — Academic Homepage v4

A lightweight static academic homepage designed for GitHub Pages, with a separate photography gallery.

## Deploy on GitHub Pages

1. Create a repository named `pazjin.github.io`.
2. Upload the **contents** of this folder to the repository root.
3. In GitHub: **Settings → Pages → Deploy from a branch → main / root**.
4. Wait for the deployment to finish, then visit `https://pazjin.github.io`.

## Main files

- `index.html` — academic homepage
- `photography.html` — photography portfolio
- `photography.js` — gallery lightbox behavior
- `cv.html` — web CV
- `styles.css` — shared site styling
- `assets/profile.jpg` — portrait
- `assets/fibucl-figure.png` — FibUCL paper figure
- `assets/aoasnet-figure.png` — AOAsNet paper figure
- `assets/photography/` — optimized gallery thumbnails and homepage previews
- `photos/` — full-size photography images
- `papers/` — local publication PDFs

The academic homepage keeps photography near the end so publications and research remain the primary focus.
