# Yuxin Jin — Academic Homepage v3

A lightweight static academic homepage designed for GitHub Pages.

## Deploy on GitHub Pages

1. Create a repository named `pazjin.github.io` (or any repository if you prefer a project site).
2. Upload the **contents** of this folder to the repository root.
3. In GitHub: **Settings → Pages → Deploy from a branch → main / root**.
4. Your site will become available after GitHub finishes the Pages deployment.

## Main files

- `index.html` — homepage
- `cv.html` — web CV
- `styles.css` — site styling
- `assets/profile.jpg` — portrait
- `assets/fibucl-figure.png` — figure from the FibUCL paper
- `assets/aoasnet-figure.png` — figure from the AOAsNet paper
- `papers/` — local publication PDFs

The site intentionally does not publish a phone number, home address, or GPA.
